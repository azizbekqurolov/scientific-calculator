# Scientific Calculator

A command-line scientific calculator built with Python.

This is my first serious Python project. I built it to strengthen my understanding of Python fundamentals, functions, input validation, error handling, loops, conditional statements, and mathematical operations.

## Features

The calculator supports 16 operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Power
6. Square root
7. Factorial
8. Absolute value
9. Sine
10. Cosine
11. Tangent
12. Common logarithm (log₁₀)
13. Natural logarithm (ln)
14. Exponential (eˣ)
15. Percentage
16. Reciprocal

## Error Handling

The calculator handles several invalid inputs and mathematical edge cases, including:

- Invalid menu choices
- Non-numeric input
- Division by zero
- Square roots of negative numbers
- Factorials of negative numbers
- Logarithms of zero or negative numbers
- Reciprocal of zero
- Undefined tangent values

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository.
3. Open the project folder.
4. Run `python calculator.py`.
